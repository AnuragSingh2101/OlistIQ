## How to Capture

1. Run locally: `streamlit run app.py`
2. Navigate to each tab
3. Use `Win+Shift+S` (Windows) or `Cmd+Shift+4` (Mac)
4. Save as PNG in this folder
5. Commit and push to GitHub
